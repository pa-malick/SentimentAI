ARCHITECTURE DU PROJET - SentimentAI 2050
Master 2 Intelligence Artificielle et Data Science
=========================================================

DESCRIPTION GENERALE
---------------------
Ce projet est un systeme complet d'analyse de sentiment en NLP.
Il compare trois approches differentes sur le dataset IMDB (50 000 critiques de films)
et expose les resultats via une interface web Flask avec un design futuriste.

FLUX DE DONNEES
---------------

1. Chargement
   load_dataset("imdb") -> 25 000 exemples train + 25 000 test
   Cache en pickle pour les relances ulterieures

2. Preprocessing (modeles classiques uniquement)
   Texte brut -> clean_text() -> TF-IDF -> matrice sparse

3. Preprocessing DistilBERT
   Texte brut -> tokenizer BERT -> input_ids + attention_mask

4. Entrainement
   Classiques : sklearn fit() en quelques secondes/minutes
   DistilBERT : boucle d'entrainement PyTorch sur plusieurs epochs

5. Evaluation
   Predictions sur le jeu de test
   Metriques + graphiques -> dossier metrics/

6. Inference via Flask
   POST /predict -> utils.predict_sentiment() -> JSON de reponse


CHOIX TECHNIQUES
----------------

TF-IDF + bigrammes (1,2) :
  Capture "not good", "very bad" comme features importantes
  max_features=30000 pour equilibrer performance et memoire

sublinear_tf=True dans TF-IDF :
  Reduit l'impact des mots tres frequents (log scaling)

DistilBERT-base-uncased :
  60% plus leger que BERT, 97% de ses performances
  Pas de casse = moins de bruit pour les critiques informelles

max_length=256 pour DistilBERT :
  Les critiques IMDB depassent rarement 256 tokens utiles
  Equilibre entre contexte capture et vitesse

AdamW + linear warmup scheduler :
  Standard pour le fine-tuning de Transformers
  weight_decay=0.01 pour regulariser

Gradient clipping (max_norm=1.0) :
  Evite les explosions de gradient lors du fine-tuning


RESULTATS ATTENDUS
------------------

Logistic Regression  : accuracy ~89-91%
Random Forest        : accuracy ~84-87%
DistilBERT fine-tune : accuracy ~92-94%

La Regression Logistique est souvent surprenante : presque aussi bonne que
DistilBERT avec un temps d'entrainement radicalement inferieur.
C'est une lecon importante en NLP pratique.
